## The company brain, in one paragraph

A company's knowledge in plain Markdown, in git, with agents on top and
connectors out to the tools it already pays for. The demo company is fictional;
the architecture is the one I run a real company on. A chief agent builds it one
piece at a time — operations, customer service, marketing, a founder's desk —
and every step is in the [build log](company-brain/studio/BUILD-LOG.md).
Clone it and swap the fictional company for yours.
